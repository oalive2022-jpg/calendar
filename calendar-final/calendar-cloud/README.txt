# 📅 月間カレンダー管理システム（クラウド版・GitHub + Render）

## 構成
```
calendar-server/
├── server.js          サーバー本体
├── render.yaml         Renderデプロイ設定
├── package.json        依存関係
├── .gitignore           Git除外設定
├── public/
│   ├── login.html       ログイン画面
│   ├── admin.html       管理者画面
│   └── calendar.html    カレンダー画面
└── data/.gitkeep        データ保存フォルダ（空でOK）
```

---

## デプロイ手順（GitHub + Render）

### 1. GitHubにアップロード
1. https://github.com で新しいリポジトリを作成（Public/Privateどちらでも可）
2. このフォルダの中身をすべてアップロード
   （GitHub Desktop を使うと簡単。または「Upload files」からドラッグ＆ドロップ）

### 2. Renderでデプロイ
1. https://render.com にアクセスして無料アカウント作成（GitHubアカウントでログイン可）
2. 「New +」→「Web Service」
3. 先ほどのGitHubリポジトリを選択
4. 以下の設定を確認（render.yamlがあれば自動入力されます）：
   - Build Command: npm install
   - Start Command: node server.js
   - Plan: Free
5. 「Create Web Service」をクリック
6. 数分待つとデプロイ完了。発行されたURL（例: https://calendar-server-xxxx.onrender.com）が
   今後ずっと使える固定アドレスになります

### 3. アクセス
```
https://（発行されたURL）/login.html
```

## ログイン方法

■ 管理者
  ユーザー名: admin
  パスワード: admin1234（必ず変更してください）

■ 一般ユーザー
  管理者が追加したユーザー名・パスワードでログイン

---

## 注意事項

- Render無料プランは15分間アクセスがないとスリープします。
  スリープ中の初回アクセスのみ起動に20〜30秒ほどかかりますが、データは消えません。
- データは永続ディスク（/data）に保存されるため、再デプロイしても消えません。
- パスワードやユーザー情報は config.json / users.json に保存されます（Gitには含まれません）。

## 新機能：通知（リマインダー）

- カレンダー画面右上の「🔕 通知オフ」ボタンを押すと、ブラウザの通知許可を求められます。
  許可すると「🔔 通知オン」に変わり、設定した予定の通知が届くようになります。
- iPhoneの場合、Safariで「ホーム画面に追加」した状態（PWA）でないと通知が届きません。
  通常のSafariタブのままでは機能しないのでご注意ください。
- 予定を追加・編集する画面で「🔔 通知」欄から、何分前に通知するか選べます
  （時刻が設定されている予定のみ対応）。

## 新機能：固定スケジュールの「この日だけ」変更

- カレンダーで日付を選び、その日の固定予定（オレンジ色の「固定」タグが付いたもの）をタップすると、
  「この日だけ変更」または「この日は休み」を選べる画面が開きます。
- 変更・休みにしても、他の週・他の日の同じ固定予定には影響しません。
- 「元に戻す」ボタンで、その日だけの変更を取り消して通常の固定予定に戻せます。
